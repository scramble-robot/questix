QUESTiX DDTモータ ID設定マニュアル

ddt_checker.py を使用して、新品または交換用DDTモータのIDを確認・変更する手順です。

安全な作業のために

  • ID設定作業中は、DDTモータを1台だけ接続してください。
  • 複数台を同じRS485バスへ接続したままID変更すると、複数モータが同じIDになるおそれがあります。
  • QUESTiX Launcher、ROS 2の走行ノード、他のシリアル通信ツール、別の ddt_checker.py は終了してください。
  • 非常停止ボタンを押せる状態で作業してください。

作業の前提

使用ツール

ddt_checker.py

標準ポート

/dev/ttyACM0

標準ボーレート

57600

走行用DDTモータID

左モータ: 4
右モータ: 5

1. ddt_checker.py を起動する

端末でQUESTiXリポジトリへ移動し、ddt_checker.py を起動します。

cd questix
python3 ddt_checker.py
  • Port Status: 利用可能 (/dev/ttyACM0@57600) と表示されることを確認します。
  • 表示されない場合は、モータ電源 (非常停止解除状態)、USB/RS485変換器、ポート名、権限を確認します。

2. 「情報更新」で現在IDを確認する

GUIの「情報更新」ボタンを押します。端末には送信コマンド、受信バイト数、受信データが表示されます。

表示値の見方

項目意味確認ポイント
ID現在モータID変更前後で期待値になっているか確認します。
Modeモータの応答モード値通常確認用です。
Current電流値とraw値停止中は小さい値になる想定です。
Velocity速度RPM停止中は 0 rpm になる想定です。
Temperatureこの応答には温度が含まれませんN/A (not in this response) と表示されます。
Position位置フィールドのraw値16進数で表示されます。
Fault故障コード0x00 ならエラーなしです。

3. ID設定欄へスクロールする

ウィンドウ右側のスクロールバーを下へ動かすと、下部の「ID設定」欄が表示されます。

  • 対象モータが1台だけ接続されていることを再確認します。
  • 「新しいID (0〜255)」欄に設定したいIDを入力します。
  • 右モータとして使う場合は 5 を入力します。

4. 「ID変更」を押す

「ID変更」ボタンを押すと、完了ダイアログが表示されます。

  • 完了ダイアログが表示されたら、内容を確認して OK を押します。
  • モータ電源を入れ直す、またはモータを再接続します。
  • 再接続後、再度「情報更新」を押してIDが変更されていることを確認します。

5. ID変更後の確認

  • 「情報更新」を押します。
  • ID欄が設定した値、例では 5 になっていることを確認します。
  • Fault: 0x00 であることを確認します。
  • 右モータをID 5にした後、左モータID 4と同時接続する場合はID重複がないことを確認します。

トラブルシュート

ポートが利用不可になる

ls -l /dev/ttyACM* /dev/ttyUSB* 2>/dev/null || true
fuser -v /dev/ttyACM0
  • 別プロセスがポートを使用していないか確認してください。
  • USB/RS485変換器を抜き差しした場合、ポート名が変わることがあります。

「情報更新」で応答がない

  • モータ電源を確認してください。非常停止解除状態にしてください。
  • RS485のA/B配線が逆でないか確認してください。
  • ボーレートが 57600 で合っているか確認してください。
  • 対象モータが1台だけ接続されているか確認してください。

Temperature が N/A と表示される

現在の「情報更新」応答には温度フィールドが含まれていないため、N/A (not in this response) と表示されます。異常ではありません。
