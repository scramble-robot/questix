          いま走っているのは

        練習モードでは、生徒が教材で安全確認のチェックを入れると、走行実験（ステップ応答・壁の前で止めるPID・速さの往復・
        決めた距離の走行・動作確認）が低速でロボットを動かします。コントローラーはそのまま使えます：
        教材の走行中でもスティックを倒せば、すぐにコントローラーの操作に切り替わり、教材の走行は止まります
        （切り替えノード twist_arbiter）。起動し直す必要はありません。
      
    
      
    
        授業の外で走らせたくないときは「教材からの走行を止める」を押します（配信中のブリッジを自動で起動し直すので、
        生徒の接続が数秒切れます）。大会モードでは走行できず、練習モードに戻すと再開します。
        上限は前後 0.3 m/s・回転 1.0 rad/s（questix_lab_bridge の設定）で、教材の画面が閉じたり通信が 0.5 秒途切れたりすると止まり、
        どの端末の停止バーでも止められます。
      
    
    
    

    
    
      
    
        教材からの発射
      
    
      
      
    
        
        配信が止まっています
      
    
      
    
        
    
          いま操作しているのは
          —
        
    
      
    
      
      

      
      

      
      
        
        
      
      

      
      
        練習モードでは、生徒が教材で「発射する方向に人がいない・的の周りに人がいない」のチェックを入れると、
        ローラーの回転・発射台の角度・ディスク1枚の発射を教材から操作できます。コントローラーが優先です：
        ローラーや発射のボタンを押すと、すぐにコントローラーの操作に切り替わり、教材の操作は止まります。
      
      
      
      
        授業の外で使わせたくないときは「教材からの発射を止める」を押します（配信中のブリッジを自動で起動し直すので、
        生徒の接続が数秒切れます）。大会モードでは使えず、練習モードに戻すと再開します。
        ローラーは最大 80%、発射はローラーが1秒回ってから・前の発射から2秒あけて1枚ずつ（questix_lab_bridge の設定）。
        教材の画面が閉じたり通信が 0.5 秒途切れたり 30 秒たったりするとローラーは止まり、どの端末からでも止められます。

      教材の設定
      
      
      
        
      
          
          
        
      
        
      
          
        
      
      
      
      
      
      設定は、次に配信を開始したときから有効になります。自動開始は最初からオンです。オンの間は、教材のページとロボットの値を、同じネットワークの全員が開けます（走行と発射は「教材からの走行」「教材からの発射」で許可したときだけ）。大会モードに切り替えると、配信を止めて自動開始もオフにします（大会モードの間は自動で開始しません）。練習モードに戻すと、自動開始をオンに戻して配信を開始します。
