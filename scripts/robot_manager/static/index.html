ブラウザ・スマホで操作

コントローラーを Web に設定して保存し、サービスを起動・再起動してください。

PC・iPhone・iPad はアプリ不要です。「ブラウザで操作」を開き、タッチ・マウスまたはキーボードを選べます。

操作する端末とロボットを同じネットワークに接続してください。localhost ではなくロボットの IP アドレスを指定します。ポートや認証トークンを変更した場合は URL に反映してください。
