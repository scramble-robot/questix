          いま走っているのは
          —
        
    
      
    
      
      

      
      

      
      
        生徒が教材で安全確認のチェックを入れると、走行実験（ステップ応答・壁の前で止める・速さの往復・
        決めた距離の走行・動作確認）で、教材から低速でロボットを走らせられます。コントローラーはいつでも優先です：
        スティックを倒せば、すぐにコントローラーの操作に切り替わり、教材の走行は止まります。
        切り替えると配信中のブリッジを起動し直すので、生徒の接続が数秒切れます。
      
      
      
      
        先生・技術者向けの詳しい情報
        
      
          
      
            ロボット（ROS_DOMAIN_ID）
            —
          
      
        
      
        
        
        
        
          練習用の起動（questix_core、enable_autoreferee:=false）では切り替えノード twist_arbiter が入り、
          コントローラーと教材の指令（/target_twist/lab）のどちらかを /target_twist に渡します。
          大会用の起動（enable_autoreferee:=true）には入らないため、教材からは走らせられません。
          上限は前後 0.3 m/s・回転 1.0 rad/s（questix_lab_bridge の設定）で、教材の画面が閉じたり通信が
          0.5 秒途切れたりすると止まり、どの端末の停止バーでも止められます。
        
        
      
        
    
        

    
        
      
        
        教材からの発射
      
        
      
      
        
        
        配信が止まっています
      
        
      
        
        
        
      
        
      
        
      
        
        
        
          いま操作しているのは
          —
        
        
      
        
      
          

      
          

      
          
        生徒が教材で「発射する方向に人がいない・的の周りに人がいない」のチェックを入れると、
        ローラーの回転・発射台の角度・ディスク1枚の発射を教材から操作できます。コントローラーが優先です：
        ローラーや発射のボタンを押すと、すぐにコントローラーの操作に切り替わり、教材の操作は止まります。
        切り替えると配信中のブリッジを起動し直すので、生徒の接続が数秒切れます。
      
          
      
          
        先生・技術者向けの詳しい情報
        
            
        
            
          練習用の起動では、ローラー（esc_motor_control）と発射台（shot_component）が教材の入力
          （/roller/lab・/shot/lab/*）を受け付けます。大会用の起動（enable_autoreferee:=true）では受け付けません。
          ローラーは最大 80%、発射はローラーが1秒回ってから・前の発射から2秒あけて1枚ずつ（questix_lab_bridge の設定）。
          教材の画面が閉じたり通信が 0.5 秒途切れたり 30 秒たったりするとローラーは止まり、どの端末からでも止められます。

            設定は、次に配信を開始したときから有効になります。自動開始は最初からオンです。オンの間は、同じネットワークの誰でも教材のページを開いて、ロボットの値を見られます（走行と発射は「教材からの走行」「教材からの発射」で許可したときだけ）。大会モードに切り替えると、配信を止めて自動開始・走行・発射をオフにします（大会モードの間は配信しません）。練習モードに戻すと、大会モードの前に選んでいた設定（自動開始・走行・発射）に戻します。
